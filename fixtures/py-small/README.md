# Shop example

A small Python shop for exploring Gitvur. Start with `app.py` and follow the order service into catalogue and storage code.

## Getting oriented

Read the [architecture guide](docs/architecture.md) for the main responsibilities. The [order service](shop/orders.py#L14-L17) coordinates a purchase. `OrderService.receipt` prepares the receipt.

## Reading the example

The repository is sample data. Gitvur reads its structure and source without running it.
